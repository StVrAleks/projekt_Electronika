# 🎮 Ретро-игра «Электроника: Ну, погоди!»

Современная реализация легендарной советской карманной электронной игры «Ну, погоди!» (Электроника ИМ-02), написанная на чистом **TypeScript** с использованием объектно-ориентированного подхода.

## 🛠 Технологический стек
* **Язык:** TypeScript (строгая типизация)
* **Сборщик:** Vite / Webpack / ESBuild *(выберите ваш вариант)*
* **Интерфейс:** HTML5, CSS3 (BEM, Flexbox/Grid)
* **Архитектура:** Модульная структура, менеджеры состояний (State Management), менеджеры промисов для анимации.

---

## ✨ Особенности реализации
* **Полный перенос логики оригинала:** Поддержка "Игры А" (3 лотка) и "Игры Б" (4 лотка).
* **Умный рандомайзер:** Реализована механика "мешка" (Bag system), исключающая повторение одинаковых лотков подряд и делающая геймплей честным.
* **Динамическая скорость:** Прогрессивное ускорение скатывания яиц в зависимости от набранных очков (каждые 25/50/75 баллов) без накопления багов таймера.
* **Система штрафов:** Подсчет пропущенных яиц с логикой обнуления штрафных очков при достижении 200 и 500 баллов.
* **Асинхронные анимации:** Управление движением объектов на экране построено на `Promise` и `setTimeout`, что гарантирует плавность и независимость потоков.

## 📂 Структура проекта
* `src/main.ts` — инициализация игры, игровой цикл и обработка логики.

* `core/gameConfig.ts` — единая конфигурация игровых констант, скоринга и таймингов.
* `core/gameInit.ts` — инициализация DOM (кэширование элементов в однм месте), объекта svg (логотип)
* `core/gameState.ts` — вынос глобальных переменных и их состояний.

* `services/buttonManager.ts` — класс по управлению кнопками.
* `services/clearTimer.ts` — очищения таймеров игры при переключении режимов.
* `services/promisesManager.ts` — управление асинхронными таймерами и шагами анимации.
* `services/recordsManager.ts` — класс по работе с рекордами: сохранение в localStorage и просмотр.
* `services/soundManager.ts` — управление звуками.
* `services/timeService.ts` —управление отображением текущего времени.
* `services/visibleManager.ts` — управление стилями через классы (opacity).

* `utils/add_canvas.ts` — добавление canvas на игровое поле ( трава, кусты, забор, точки над вторым индикатором ).
* `utils/add_svg.ts` — добавление элементов svg (логотип).
* `utils/instructionSVG.ts` — загрузка анимированной инструкции.
* `utils/randomizer.ts` — алгоритм случайного выбора лотков на основе системы мешка.

## 🔧 Запуск проекта локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в папку с проектом:
   ```bash
   cd projekt_Electronika
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите локальный сервер для разработки:
   ```bash
   npm run dev
   ```
