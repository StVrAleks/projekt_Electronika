# projekt_Electronika
# Игра «Ну, погоди!» (Электроника ИМ-02) 🎮

Итоговое задание по курсу "Разработка веб-приложений на JS"
Пет-проект Улучшила начальный проект для демонстрации навыков проектирования чистой архитектуры на стороне клиента.

## 🏗 Архитектурные решения
При разработке основной упор был сделан на масштабируемость и отказоустойчивость:

*   **State Management (Управление состоянием):** Реализован единый источник истины `gameState` (паттерн Singleton), что исключает рассинхронизацию данных между модулями.
*   **Game Randomizer (Алгоритм перемешанного мешка):** Для предотвращения раздражающих повторов в игре (одинаковые склоны подряд) реализован алгоритм на основе «мешка» индексов. Числа выбираются без повторений внутри цикла, что улучшает геймплей.
*   **Async Animation Engine:** Плавность движения объектов (яиц и зайца) реализована через цепочки `Promise`, что позволило избежать «ада колбэков» (Callback Hell).
*   **Data Persistence:** Вместо серверного API используется `LocalStorage` с оберткой `RecordsManager`, включающей валидацию данных (try/catch) и защиту от XSS.

## 🛠 Стек технологий
*   **JavaScript (ES6+):** Модульная система (Import/Export), Классы.
*   **DOM API:** Кэширование элементов для оптимизации производительности в игровом цикле.
*   **CSS3:** Использование `rem` и `vw/vh` для обеспечения полной адаптивности консоли под любые разрешения экрана.
*   **Jest:** Unit-тестирование игровой логики.

## 🚀 Запуск проекта
1. Склонируйте репозиторий.
2. Установите зависимости для тестов (необязательно): `npm install`.
3. Запустите локальный сервер:
   ```bash
   npx serve
   ```
4. Откройте `http://localhost:3000` в браузере.
